Listing sources by region

These are the marketplaces, auctions, classifieds and enthusiast forums Car Compass links to (110+ marketplaces and 50+ forums).

  • Verified link We opened a test search (e.g. Toyota Supra, Porsche 911) and the site showed filtered results (checked from our test machine or, for sites that block it, an outside fetch).
  • Deep link The site accepts the filtered URL, but we could not fully confirm the results (for example, results load only after you set a location).
  • Browser link Automated checks were blocked (captcha, 403 or login), so the site’s standard public URL format is used. It should work in your browser.
  • Search on site No reliable filtered link exists, so the button opens the site’s own search for you to type the make and model.
  • Year range: about a third of the marketplaces accept a year range in the link. On the others, the results page marks the link “Year range not applied”, so set the years on the site. A page with no results usually means that market has no matching car for sale right now.
  • Stock checked Nightly stock check: every night an automatic checker opens the links for about six popular searches (around 40 in total, so each is rechecked weekly) and records what each marketplace page showed. On the results page, sites that had matching cars are listed first with the check date (and the site’s own result count when we could read it). Sites that showed no matching cars move to a folded “No matching cars at last check” group and are left out of “Open all”. Links that were broken (an error or not-found page) are hidden, with a note saying how many. Pages we couldn’t read, because of a captcha, a login or a bot block, stay in their normal place. Nothing is invented: if a search hasn’t been checked, the page looks the same as before. Results older than 21 days are dropped.
  • Forum search via Google The forum has no public search link, so this opens a Google search limited to that forum for “for sale” posts. These are forum posts, not verified listings.

Forums & communities

Enthusiasts often list cars in forum classifieds. General communities appear in every search; brand and model forums appear when your search matches the brands shown on each card.
